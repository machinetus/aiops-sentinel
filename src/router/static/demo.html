运维控制台 业务系统
建议开两个窗口：本页点按钮触发异常，切到「运维控制台」看告警流 / 事件状态机 / 任务分派实时流动；飞书群同步收卡片。

① 假死自愈

SCENARIO · PROCESS DOWN

对业务进程执行 SIGKILL 并停止服务，模拟宕机。Agent 应全自动恢复，无需人工。

预期链路：≤15s 进程告警 → Router 分诊 → OpsWorker 白名单重启 → 复检 3×10s → resolved → 飞书绿卡

② 代码缺陷 → LLM 修复

SCENARIO · CODE BUG

注入 10 次脏数据（amount=abc），触发 ValueError 500。Agent 诊断根因、生成补丁与 PR，等你人工合并。

预期链路：告警卡 → LLM 根因卡 → 修复任务 → 沙箱测试 → PR 卡 → 你去 GitHub 合并 → 自动部署复测 → 绿卡

③ 异常流量 → 限流

SCENARIO · TRAFFIC

25 秒 × 50 并发压测搜索接口。流量探针检测 QPS 超阈值后自动限流，到期自动解除。

预期链路：QPS 告警 → Router 派发 set_rate_limit → 业务页防护状态显示限流 → 到期解除 → 绿卡

④ 安全负测试

SECURITY · WHITELIST DENY

注入一个越权任务（action=rm_rf_slash），验证三重门拒绝、审计留痕与转人工。

预期链路：whitelist_deny 审计 → 任务 failed → 事件 escalated → 飞书红色转人工卡

⑤ 重置演示基线

RESET · v0.1-base

把业务系统重置回带缺陷的演示基线（v0.1-base）并重启，便于场景二重复演练。

操作：deploy 克隆 → reset --hard v0.1-base → 重启 demo-app → bug_mode=type_bug
